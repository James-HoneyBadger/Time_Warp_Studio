# Keyboard Shortcuts Reference

Complete keyboard shortcut reference for **Time Warp Studio**.
Time Warp Studio uses a **Borland Turbo-style** keymap. Press **Shift+F1** (or **Ctrl+?**)
inside the IDE to open the Keyboard Shortcuts dialog, which is generated from the live menus.

---

## File

|----------|--------|
| Ctrl+N | New file |
| F3 / Ctrl+O | Open file |
| F2 / Ctrl+S | Save file |

| Ctrl+Shift+H | Export session as HTML |
| Ctrl+P | Print code |
| Ctrl+Alt+V | Version history |
| Ctrl+, | Preferences |

## Turbo Function-Key Bar (F1–F10)

The bottom Function-Key Bar follows the held modifier (**Shift** or **Ctrl**); click the
**FN** badge to cycle layers manually. Every label is the real key binding.

| Key | Normal Layer | Shift Layer (`⇧`) | Ctrl Layer (`^`) |
|-----|--------------|-------------------|------------------|
| F1 | Help | Keyboard Shortcuts | Keyword Inspector |
| F2 | Save | Save As… | Reset Program |
| F3 | Open | Browse Examples | Lessons |
| F4 | Document Outline | Find in Files | — |
| F5 | Zoom (focus mode) | Split Editor | Show Errors Only |
| F6 | Next Pane | Telemetry HUD | — |
| F7 | Trace Into | CRT Effects | Pause |
| F8 | Step Over | Step Out | Toggle Breakpoint |
| F9 | Run | Run Selection | Debug / Continue |
| F10 | Command Palette | Cycle Theme | — |

## Tips

- Most shortcuts are also available via the menu bar.
- The **Shift+F1** dialog is built from the live menus, so it always matches the current bindings.
- **F1** shows help for the currently active language; if no specific help exists it falls back to the User Manual.
