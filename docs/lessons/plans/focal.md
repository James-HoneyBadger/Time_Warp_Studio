## First Steps in FOCAL

`focal_first_steps` · beginner · 3 checkpoints

Line labels, printing, and the two-decimal habit.

### Learning objectives

- Print text and a value
- Store a number and print it
- Repeat a statement with FOR

### Teacher notes

FOCAL labels are NN.NN - a group number and a line number, each up to two digits. Numbers print with two decimal places unless a %n format says otherwise, which is the first thing learners ask about.

### Checkpoints

#### 1. Say hello

Print exactly: Hello, World!

Handout file: `focal_first_steps-1.foc` · checked by prints: Hello, World!

Starting point:

```text
01.10 T "Hello"
01.20 Q
```

Worked answer:

```text
01.10 T "Hello, World!"
01.20 Q
```

Hints, in the order a learner should see them:

1. T is TYPE: it prints what follows.
2. The text goes in quotes: T "Hello, World!"

#### 2. Store and print

Put 5 into X and print it as X=5.00.

Handout file: `focal_first_steps-2.foc` · checked by prints: X=5.00

Starting point:

```text
01.10 S X=2
01.20 T "X=",X
01.30 Q
```

Worked answer:

```text
01.10 S X=5
01.20 T "X=",X
01.30 Q
```

Hints, in the order a learner should see them:

1. S is SET: it stores a value in a variable.
2. Change the value assigned to X.

#### 3. Count with FOR

Print I=1, I=2 and I=3, one per line.

Handout file: `focal_first_steps-3.foc` · checked by prints: I=1 / I=2 / I=3

Starting point:

```text
01.10 FOR I=1,2;T %0,"I=",I
01.20 Q
```

Worked answer:

```text
01.10 FOR I=1,3;T %0,"I=",I
01.20 Q
```

Hints, in the order a learner should see them:

1. FOR repeats the rest of the line.
2. %0 sets no decimal places, so the number prints as a whole number.

## Branching in FOCAL

`focal_branching` · intermediate · 3 checkpoints

FOCAL has no comparisons - it branches on a sign.

### Learning objectives

- Branch on the sign of an expression
- Call a group of lines with DO
- Jump to a labelled line with GOTO

### Teacher notes

This is the lesson that makes FOCAL FOCAL. IF (X) a,b,c goes to a when X is negative, b when it is zero and c when it is positive, and there is no way to write 'if X is greater than 5' except by subtracting. Draw the three-way branch on the board first.

### Checkpoints

#### 1. Positive, zero or negative

When N is 7, print POSITIVE.

Handout file: `focal_branching-1.foc` · checked by prints: POSITIVE

Starting point:

```text
01.10 S N=-7
01.20 I (N) 1.40,1.40,1.30
01.30 T "POSITIVE"
01.40 Q
```

Worked answer:

```text
01.10 S N=7
01.20 I (N) 1.40,1.40,1.30
01.30 T "POSITIVE"
01.40 Q
```

Hints, in the order a learner should see them:

1. The third target of an IF is taken when the expression is positive.
2. Set N to a positive number.

#### 2. Call a group

Use DO to run the group at 2.10 and print INSIDE.

Handout file: `focal_branching-2.foc` · checked by prints: INSIDE

Starting point:

```text
01.10 T "NOT INSIDE"
01.20 Q
02.10 T "INSIDE"
```

Worked answer:

```text
01.10 DO 2.10
01.20 Q
02.10 T "INSIDE"
```

Hints, in the order a learner should see them:

1. DO runs a group of lines starting at a label.
2. Replace the first print with DO 2.10.

#### 3. Jump to a label

Print LANDED and never print NOT REACHED.

Handout file: `focal_branching-3.foc` · checked by prints: LANDED

Starting point:

```text
01.10 T "NOT REACHED"
01.20 GOTO 1.30
01.30 T "LANDED"
01.40 Q
```

Worked answer:

```text
01.10 GOTO 1.30
01.20 T "NOT REACHED"
01.30 T "LANDED"
01.40 Q
```

Hints, in the order a learner should see them:

1. GOTO jumps to a line label.
2. The label for line 30 in group 1 is 1.30.
