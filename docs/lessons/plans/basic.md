## First Steps in BASIC

`basic_first_steps` · beginner · 3 checkpoints

Print text, store numbers in variables, and do arithmetic.

### Learning objectives

- Write a PRINT statement that displays text
- Store a value in a variable and print it
- Build an expression from variables

### Teacher notes

The first lesson in the studio. Learners who have never typed a program before should be shown how to press Run before anything else. The commonest error is a missing closing quote, which BASIC reports clearly, so let them meet it.

### Checkpoints

#### 1. Say hello

Use PRINT to display exactly: Hello, World!

Handout file: `basic_first_steps-1.bas` · checked by prints: Hello, World!

Starting point:

```basic
10 REM Add a PRINT statement on line 20
20 REM ... and END the program on line 30
30 END
```

Worked answer:

```basic
10 REM Add a PRINT statement on line 20
20 PRINT "Hello, World!"
30 END
```

Hints, in the order a learner should see them:

1. PRINT displays whatever follows it.
2. Text goes inside double quotes: PRINT "Hello, World!"

#### 2. Variables and arithmetic

W and H hold a rectangle's width and height. Store W \* H in A and print A.

Handout file: `basic_first_steps-2.bas` · checked by prints: 42

Starting point:

```basic
10 LET W = 6
20 LET H = 7
30 REM Store W * H in A
40 REM ... then print A
50 END
```

Worked answer:

```basic
10 LET W = 6
20 LET H = 7
30 LET A = W * H
40 PRINT A
50 END
```

Hints, in the order a learner should see them:

1. Arithmetic uses \* for multiply and / for divide.
2. Use LET A = W \* H on line 30, then PRINT A on line 40.

#### 3. Add them up

The loop visits every number from 1 to 10. Add each one into S, then print S.

Handout file: `basic_first_steps-3.bas` · checked by prints: 55

Starting point:

```basic
10 LET S = 0
20 FOR I = 1 TO 10
30 REM Add I into S here
40 NEXT I
50 PRINT S
60 END
```

Worked answer:

```basic
10 LET S = 0
20 FOR I = 1 TO 10
30 LET S = S + I
40 NEXT I
50 PRINT S
60 END
```

Hints, in the order a learner should see them:

1. S starts at 0 and grows as the loop runs.
2. Inside the loop, add the current value of I: LET S = S + I

## Loops and Decisions in BASIC

`basic_loops` · intermediate · 3 checkpoints

Repeat work with FOR/NEXT and choose with IF/THEN.

### Learning objectives

- Change a loop's bounds to repeat work a different number of times
- Select work inside a loop with a condition
- Keep a running total across iterations

### Teacher notes

The step from 'a program runs' to 'a program decides'. Watch for a learner who puts NEXT inside the IF: the loop then stops after one pass and the output is confusing rather than obviously wrong.

### Checkpoints

#### 1. Count with FOR

Print the numbers 1 to 5, one per line, using the loop.

Handout file: `basic_loops-1.bas` · checked by prints: 1 / 2 / 3 / 4 / 5

Starting point:

```basic
10 FOR I = 1 TO 3
20 PRINT I
30 NEXT I
40 END
```

Worked answer:

```basic
10 FOR I = 1 TO 5
20 PRINT I
30 NEXT I
40 END
```

Hints, in the order a learner should see them:

1. The loop already prints. Change how far it counts.
2. FOR I = 1 TO 5

#### 2. Only the even numbers

Loop from 1 to 10 but print a number only when it is even.

Handout file: `basic_loops-2.bas` · checked by prints: 2 / 4 / 6 / 8 / 10

Starting point:

```basic
10 FOR I = 1 TO 10
20 PRINT I
30 NEXT I
40 END
```

Worked answer:

```basic
10 FOR I = 1 TO 10
20 IF I MOD 2 = 0 THEN PRINT I
30 NEXT I
40 END
```

Hints, in the order a learner should see them:

1. MOD gives the remainder, so I MOD 2 is 0 for an even number.
2. IF I MOD 2 = 0 THEN PRINT I

#### 3. Make 55

Total the numbers from 1 to 10 and print the total.

Handout file: `basic_loops-3.bas` · checked by prints: 55

Starting point:

```basic
10 LET T = 0
20 FOR I = 1 TO 10
30 LET T = T + 1
40 NEXT I
50 PRINT T
60 END
```

Worked answer:

```basic
10 LET T = 0
20 FOR I = 1 TO 10
30 LET T = T + I
40 NEXT I
50 PRINT T
60 END
```

Hints, in the order a learner should see them:

1. The loop body adds the wrong thing to the total.
2. Add I, not 1: LET T = T + I
