## Drawing with CHIP-8

`chip8_drawing` · beginner · 3 checkpoints

A framebuffer, a sprite, and one instruction that puts them together.

### Learning objectives

- Draw a sprite with DRW
- Understand that one byte of data is one row of eight pixels
- Use the machine's built-in hex font

### Teacher notes

CHIP-8 is assembled and run whole, so a mistake is reported with an address rather than a line number. The display is 64x32 and each data byte is one row with the leftmost pixel in the highest bit, which is worth drawing on the board: 0xF0 is the left four pixels of a row.

### Checkpoints

#### 1. Light one pixel

The data is already here. Draw it and stop.

Handout file: `chip8_drawing-1.ch8` · checked by draws: shapes=2

Starting point:

```asm
start: LD I, dot
       HALT
dot:   DB 0x80
```

Worked answer:

```asm
start: LD I, dot
       DRW V0, V1, 1
       HALT
dot:   DB 0x80
```

Hints, in the order a learner should see them:

1. DRW takes the x register, the y register and the number of rows.
2. Put DRW V0, V1, 1 before HALT.

#### 2. Two rows

The sprite has two bytes. Draw both rows.

Handout file: `chip8_drawing-2.ch8` · checked by draws: shapes=7

Starting point:

```asm
start: LD I, spr
       DRW V0, V1, 1
       HALT
spr:   DB 0xF0
       DB 0x90
```

Worked answer:

```asm
start: LD I, spr
       DRW V0, V1, 2
       HALT
spr:   DB 0xF0
       DB 0x90
```

Hints, in the order a learner should see them:

1. The last number in DRW is how many bytes to draw.
2. Two rows means DRW V0, V1, 2.

#### 3. Use the built-in font

Draw the whole hex glyph for 0x41 from the machine's font.

Handout file: `chip8_drawing-3.ch8` · checked by draws: shapes=9

Starting point:

```asm
start: LD V0, 0x41
       LD I, dot
       DRW V0, V1, 1
       HALT
dot:   DB 0x80
```

Worked answer:

```asm
start: LD V0, 0x41
       LD F, V0
       DRW V0, V1, 5
       HALT
dot:   DB 0x80
```

Hints, in the order a learner should see them:

1. LD F, Vx points I at the font's drawing of the digit in Vx.
2. A font glyph is five bytes tall: use LD F, V0 and DRW V0, V1, 5.

## Sprites and Pixels in CHIP-8

`chip8_sprites` · advanced · 3 checkpoints

Frames of data, moving the draw, and what happens when pixels overlap.

### Learning objectives

- Draw a multi-row sprite from data
- Move where the next draw lands
- Explain why drawing over a lit pixel turns it off

### Teacher notes

The last checkpoint is the one worth the time: CHIP-8 has no erase instruction, and a lit pixel drawn over is turned off. That single rule is how the machine animates, and a learner who can explain it understands the display rather than just copying DRW lines.

### Checkpoints

#### 1. A three-row frame

Draw the frame data as three rows.

Handout file: `chip8_sprites-1.ch8` · checked by draws: shapes=19

Starting point:

```asm
start: LD I, frame
       DRW V0, V1, 1
       HALT
frame: DB 0xFF
       DB 0x81
       DB 0xFF
```

Worked answer:

```asm
start: LD I, frame
       DRW V0, V1, 3
       HALT
frame: DB 0xFF
       DB 0x81
       DB 0xFF
```

Hints, in the order a learner should see them:

1. The data holds three bytes.
2. DRW V0, V1, 3 draws all of them.

#### 2. Draw it twice

Draw the frame, move eight pixels right, and draw it again.

Handout file: `chip8_sprites-2.ch8` · checked by draws: shapes=37

Starting point:

```asm
start: LD I, frame
       DRW V0, V1, 3
       HALT
frame: DB 0xFF
       DB 0x81
       DB 0xFF
```

Worked answer:

```asm
start: LD I, frame
       DRW V0, V1, 3
       ADD V0, 8
       DRW V0, V1, 3
       HALT
frame: DB 0xFF
       DB 0x81
       DB 0xFF
```

Hints, in the order a learner should see them:

1. ADD V0, 8 changes where the next DRW starts.
2. Draw, add 8 to V0, then draw again.

#### 3. Draw over yourself

Now move only one pixel right before drawing again, and see what happens.

Handout file: `chip8_sprites-3.ch8` · checked by draws: shapes=9

Starting point:

```asm
start: LD I, frame
       DRW V0, V1, 3
       ADD V0, 8
       DRW V0, V1, 3
       HALT
frame: DB 0xFF
       DB 0x81
       DB 0xFF
```

Worked answer:

```asm
start: LD I, frame
       DRW V0, V1, 3
       ADD V0, 1
       DRW V0, V1, 3
       HALT
frame: DB 0xFF
       DB 0x81
       DB 0xFF
```

Hints, in the order a learner should see them:

1. One pixel right means most of the second draw lands on the first.
2. Where the two overlap the pixels are turned off, so far fewer are left lit.
