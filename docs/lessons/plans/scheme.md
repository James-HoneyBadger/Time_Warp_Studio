## Scheme Basics

`scheme_basics` · beginner · 3 checkpoints

Everything is an expression, and parentheses group them.

### Learning objectives

- Display the value of an arithmetic expression
- Define a procedure with define
- Choose between two values

### Teacher notes

Scheme is the studio's functional language and the first where the learner must count brackets. Run a program that is missing one before they write their first to show what the error looks like when it is easy to see.

### Checkpoints

#### 1. Display 42

Use display to produce exactly: 42

Handout file: `scheme_basics-1.scm` · checked by prints: 42

Starting point:

```scheme
(display (+ 20 20))
```

Worked answer:

```scheme
(display (+ 20 22))
```

Hints, in the order a learner should see them:

1. \+ adds its arguments.
2. You need the total to be 42: (+ 20 22)

#### 2. Define a procedure

Define double, which returns twice its argument, and display double of 21.

Handout file: `scheme_basics-2.scm` · checked by prints: 42

Starting point:

```scheme
(define (double x) (* x 1))
(display (double 21))
```

Worked answer:

```scheme
(define (double x) (* x 2))
(display (double 21))
```

Hints, in the order a learner should see them:

1. The body of double multiplies x by the wrong number.
2. (\* x 2)

#### 3. Choose

Display big when 5 is greater than 3, and small otherwise.

Handout file: `scheme_basics-3.scm` · checked by prints: big

Starting point:

```scheme
(display (if (> 3 5) "big" "small"))
```

Worked answer:

```scheme
(display (if (> 5 3) "big" "small"))
```

Hints, in the order a learner should see them:

1. if takes a condition, then the true branch, then the false one.
2. The comparison is the wrong way round: (> 5 3)

## Recursion and Lists in Scheme

`scheme_recursion` · intermediate · 3 checkpoints

A procedure that calls itself, and the lists it works on.

### Learning objectives

- Write a recursive procedure with a stopping case
- Work with a list
- Pass a procedure to another procedure

### Teacher notes

Recursion lands properly here because the stopping case is visible in the source. The last checkpoint introduces higher-order procedures, which is the idea Scheme exists to teach - a learner who has done it has seen the whole paradigm.

### Checkpoints

#### 1. Factorial

Make fact return 120 for 5.

Handout file: `scheme_recursion-1.scm` · checked by prints: 120

Starting point:

```scheme
(define (fact n) (if (= n 0) 1 (* n (fact n))))
(display (fact 5))
```

Worked answer:

```scheme
(define (fact n) (if (= n 0) 1 (* n (fact (- n 1)))))
(display (fact 5))
```

Hints, in the order a learner should see them:

1. A recursive procedure must call itself with a smaller argument.
2. Multiply by (fact (- n 1)), not (fact n).

#### 2. How long is a list

Display the number of items in the list 1 2 3.

Handout file: `scheme_recursion-2.scm` · checked by prints: 3

Starting point:

```scheme
(display (list 1 2 3))
```

Worked answer:

```scheme
(display (length (list 1 2 3)))
```

Hints, in the order a learner should see them:

1. length counts the items in a list.
2. (length (list 1 2 3))

#### 3. Give a procedure to another

Square every number in 1 2 3 and display the result.

Handout file: `scheme_recursion-3.scm` · checked by prints: (1 4 9)

Starting point:

```scheme
(define (square x) (* x x))
(display (list 1 2 3))
```

Worked answer:

```scheme
(define (square x) (* x x))
(display (map square (list 1 2 3)))
```

Hints, in the order a learner should see them:

1. map applies a procedure to every item of a list.
2. (map square (list 1 2 3))
