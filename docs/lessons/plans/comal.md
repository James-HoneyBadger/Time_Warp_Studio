## COMAL Basics

`comal_basics` · beginner · 3 checkpoints

Print, calculate and repeat - COMAL's structured BASIC.

### Learning objectives

- Print text and numbers
- Do arithmetic and print the result
- Repeat work with a proper FOR block

### Teacher notes

COMAL is the bridge between BASIC and a structured language: it prints the way BASIC does and loops with a proper block rather than NEXT. Use it with learners who already know BASIC to show what structure buys them.

### Checkpoints

#### 1. Say hello

Use PRINT to display exactly: Hello, World!

Handout file: `comal_basics-1.comal` · checked by prints: Hello, World!

Starting point:

```text
10 REM Print the greeting
20 END
```

Worked answer:

```text
10 PRINT "Hello, World!"
20 END
```

Hints, in the order a learner should see them:

1. Text goes inside quotes.
2. PRINT "Hello, World!"

#### 2. Arithmetic

Print the product of 6 and 7.

Handout file: `comal_basics-2.comal` · checked by prints: 42

Starting point:

```text
10 PRINT 6 + 7
```

Worked answer:

```text
10 PRINT 6 * 7
```

Hints, in the order a learner should see them:

1. COMAL uses \* for multiply.
2. Change the + to a \*.

#### 3. Count to five

Print 1, 2, 3, 4 and 5, one per line.

Handout file: `comal_basics-3.comal` · checked by prints: 1 / 2 / 3 / 4 / 5

Starting point:

```text
10 FOR I = 1 TO 3
20 PRINT I
30 NEXT I
```

Worked answer:

```text
10 FOR I = 1 TO 5
20 PRINT I
30 NEXT I
```

Hints, in the order a learner should see them:

1. The block is already complete; only the limit is wrong.
2. Change 3 to 5.

## COMAL Procedures and Decisions

`comal_procedures` · intermediate · 3 checkpoints

Group work into a procedure and branch inside a loop.

### Learning objectives

- Define a procedure and call it
- Choose between two paths with IF and ELSE
- Keep a running total inside a loop

### Teacher notes

COMAL's PROC/ENDPROC is the feature BASIC lacks entirely. The middle checkpoint is the one to linger on: COMAL requires ENDIF, which is exactly the mistake a BASIC programmer makes when they first meet a block language.

### Checkpoints

#### 1. Write a procedure

Define BOX so that CALL BOX prints exactly: Hello, World

Handout file: `comal_procedures-1.comal` · checked by prints: Hello, World

Starting point:

```text
10 PROC BOX
20 REM Print the greeting here
30 ENDPROC
40 CALL BOX
```

Worked answer:

```text
10 PROC BOX
20 PRINT "Hello, World"
30 ENDPROC
40 CALL BOX
```

Hints, in the order a learner should see them:

1. The PRINT goes inside the procedure, between PROC and ENDPROC.
2. Line 20 becomes PRINT "Hello, World"

#### 2. Decide with IF and ELSE

Grade a score of 95: print pass, not try again.

Handout file: `comal_procedures-2.comal` · checked by prints: pass

Starting point:

```text
10 SCORE = 45
20 IF SCORE >= 50 THEN
30 PRINT "pass"
40 ELSE
50 PRINT "try again"
60 ENDIF
```

Worked answer:

```text
10 SCORE = 95
20 IF SCORE >= 50 THEN
30 PRINT "pass"
40 ELSE
50 PRINT "try again"
60 ENDIF
```

Hints, in the order a learner should see them:

1. The condition is already written correctly - the value is not.
2. Set SCORE to a number that passes.

#### 3. Total a loop

Add the numbers from 1 to 10 into T and print T.

Handout file: `comal_procedures-3.comal` · checked by prints: 55

Starting point:

```text
10 T = 0
20 FOR I = 1 TO 10
30 T = T + 1
40 NEXT I
50 PRINT T
```

Worked answer:

```text
10 T = 0
20 FOR I = 1 TO 10
30 T = T + I
40 NEXT I
50 PRINT T
```

Hints, in the order a learner should see them:

1. T is being increased by the wrong amount each time.
2. Add I rather than 1.
