## First Words in Forth

`forth_first_words` · beginner · 3 checkpoints

Push numbers on the stack, run the words that combine them, and write a word of your own.

### Learning objectives

- Read a Forth program as a sequence of words, each taking what it needs from the stack
- Use \`+\`, \`DUP\` and \`\*\` to build an answer
- Define a new word with \`:\` and end it with \`;\`

### Teacher notes

Forth looks like line noise to anyone who has only met BASIC, and the fastest way through is a stack diagram on paper: every number pushed goes on a pile, and every word takes from the top. \`DUP\` is the word that confuses beginners most, because it copies rather than consumes. A stack underflow (\`. \` on an empty stack) is the commonest first error, and Forth names the word that found it.

### Checkpoints

#### 1. Two numbers, one word

Put 2 and 3 on the stack, add them with \`+\`, and print the answer with \`.\`.

Handout file: `forth_first_words-1.fs` · checked by prints: 5

Starting point:

```text
\ A word takes what it needs from the stack.
\ Push 2, then 3, then add, then print.
```

Worked answer:

```text
2 3 + . CR
```

Hints, in the order a learner should see them:

1. Forth reads left to right: \`2 3 +\` leaves a single 5 on the stack.
2. \`.\` prints the top of the stack. \`CR\` starts a new line.

#### 2. Square a number

Print 7 squared. Use \`DUP\` rather than typing the number twice.

Handout file: `forth_first_words-2.fs` · checked by prints: 49

Starting point:

```text
\ DUP copies the top of the stack, so one number can be used twice.
7
```

Worked answer:

```text
7 DUP * . CR
```

Hints, in the order a learner should see them:

1. \`DUP\` is the one word beginners expect to consume its argument; it copies instead.
2. \`7 DUP \*\` is 7 × 7.

#### 3. A word of your own

Define a word \`DOUBLE\` that multiplies by 2, then print 21 doubled.

Handout file: `forth_first_words-3.fs` · checked by prints: 42

Starting point:

```text
\ : starts a definition, ; ends it.
\ Define DOUBLE so that `21 DOUBLE` prints 42.

21 DOUBLE . CR
```

Worked answer:

```text
: DOUBLE 2 * ;
21 DOUBLE . CR
```

Hints, in the order a learner should see them:

1. The definition reads \`: DOUBLE\` … body … \`;\` on any number of lines.
2. The body is just \`2 \*\`: push 2 and multiply.

## Loops, Variables and Recursion in Forth

`forth_defining` · intermediate · 3 checkpoints

Count with DO/LOOP, keep a value in a variable, and write a word that calls itself.

### Learning objectives

- Loop a fixed number of times with \`DO\` … \`LOOP\` and read the counter with \`I\`
- Keep a value in a \`VARIABLE\` and read it back with \`@\`
- Write a recursive word using \`RECURSE\`

### Teacher notes

All three checkpoints are about where a value lives: the stack (transient, order matters), the loop counter (\`I\`, read without popping), or a variable (named, address on the stack). \`RECURSE\` exists because a definition is not finished when its body is compiled, so a word cannot simply name itself; Forth does allow the name, and this implementation registers the definition at \`:\` so either works — teach \`RECURSE\` because it is the standard spelling.

### Checkpoints

#### 1. Count to four

Define \`COUNTUP\` so that it prints \`0 1 2 3 4\` on one line.

Handout file: `forth_defining-1.fs` · checked by prints: 0 1 2 3 4

Starting point:

```text
\ DO takes `limit start`, so `5 0 DO` counts 0 to 4.
\ `I` reads the counter. `LOOP` goes back.

COUNTUP CR
```

Worked answer:

```text
: COUNTUP 5 0 DO I . LOOP ;
COUNTUP CR
```

Hints, in the order a learner should see them:

1. The body is \`I .\` — read the counter, then print it.
2. \`5 0 DO\` ends at 5, so the last number printed is 4.

#### 2. A variable

Make a \`VARIABLE\` called \`TOTAL\`, store 42 in it, and print it back.

Handout file: `forth_defining-2.fs` · checked by prints: 42

Starting point:

```text
\ VARIABLE makes a name that pushes an address.
\ `!` is ( value address -- ) and `@` is ( address -- value ).
```

Worked answer:

```text
VARIABLE TOTAL
42 TOTAL !
TOTAL @ . CR
```

Hints, in the order a learner should see them:

1. The address goes on top: value first, then the name.
2. \`TOTAL @\` pushes what the variable holds.

#### 3. Six factorial

Define \`FACT\` so that \`6 FACT .\` prints 720. Use \`RECURSE\`.

Handout file: `forth_defining-3.fs` · checked by prints: 720

Starting point:

```text
\ n! is n × (n-1)!, and 1! is 1.

6 FACT . CR
```

Worked answer:

```text
: FACT DUP 1 > IF DUP 1- RECURSE * THEN ;
6 FACT . CR
```

Hints, in the order a learner should see them:

1. Stop when the number is not greater than 1 — the \`IF\` has no \`ELSE\`, so a non-true flag leaves the number alone.
2. The multiply happens after \`RECURSE\` returns: \`DUP 1- RECURSE \*\`.
