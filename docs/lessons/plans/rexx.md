## REXX Basics

`rexx_basics` · beginner · 3 checkpoints

Say things, join strings, and store values.

### Learning objectives

- Print a line with SAY
- Do arithmetic and print the answer
- Join strings with ||

### Teacher notes

REXX is typeless: everything is a string that behaves like a number when used as one. That surprises learners who expect a declaration, so the second checkpoint (printing 6 \* 7) is the one that makes the point.

### Checkpoints

#### 1. Say hello

Use SAY to display exactly: Hello, World!

Handout file: `rexx_basics-1.rexx` · checked by prints: Hello, World!

Starting point:

```rexx
SAY 'Hello'
```

Worked answer:

```rexx
SAY 'Hello, World!'
```

Hints, in the order a learner should see them:

1. SAY prints its argument and a newline.
2. Text goes in single or double quotes.

#### 2. Arithmetic

Print the product of 6 and 7.

Handout file: `rexx_basics-2.rexx` · checked by prints: 42

Starting point:

```rexx
SAY 6 + 7
```

Worked answer:

```rexx
SAY 6 * 7
```

Hints, in the order a learner should see them:

1. REXX works out the arithmetic before SAY prints it.
2. Change + to \*.

#### 3. Join two strings

Print Hello World using concatenation.

Handout file: `rexx_basics-3.rexx` · checked by prints: Hello World

Starting point:

```rexx
SAY 'Hello' || 'World'
```

Worked answer:

```rexx
SAY 'Hello' || ' ' || 'World'
```

Hints, in the order a learner should see them:

1. || joins without adding anything.
2. Join the middle space too: 'Hello' || ' ' || 'World'

## REXX Loops and Subroutines

`rexx_loops` · intermediate · 3 checkpoints

Repeat work, use the built-in functions, and write a subroutine.

### Learning objectives

- Repeat a block until a condition is met
- Pick a word out of a string with a built-in function
- Return a value from an internal subroutine

### Teacher notes

REXX's built-in function library is the reason to teach it: WORD, LENGTH and friends do in one line what other languages do in five. RESULT is only set by a subroutine that RETURNs a value, so a missing value is usually a bare RETURN.

### Checkpoints

#### 1. Count to five

Count to 5 with a loop, then print the final count.

Handout file: `rexx_loops-1.rexx` · checked by prints: 5

Starting point:

```rexx
count = 0
DO WHILE count < 3
count = count + 1
END
SAY count
```

Worked answer:

```rexx
count = 0
DO WHILE count < 5
count = count + 1
END
SAY count
```

Hints, in the order a learner should see them:

1. The loop stops as soon as the condition is false.
2. Change the 3 to a 5.

#### 2. Pick a word out

Print the second word of 'alpha beta gamma'.

Handout file: `rexx_loops-2.rexx` · checked by prints: beta

Starting point:

```rexx
SAY WORD('alpha beta gamma', 1)
```

Worked answer:

```rexx
SAY WORD('alpha beta gamma', 2)
```

Hints, in the order a learner should see them:

1. WORD takes a string and a position.
2. The second word is position 2, not 1.

#### 3. Return a value

CALL DOUBLE with 5 so that SAY RESULT prints 10.

Handout file: `rexx_loops-3.rexx` · checked by prints: 10

Starting point:

```rexx
CALL DOUBLE 5
SAY RESULT
EXIT
DOUBLE:
RETURN ARG(1)
```

Worked answer:

```rexx
CALL DOUBLE 5
SAY RESULT
EXIT
DOUBLE:
RETURN ARG(1) * 2
```

Hints, in the order a learner should see them:

1. ARG(1) is the number the subroutine was given.
2. The subroutine has to double it before returning.
