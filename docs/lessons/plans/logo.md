## Turtle Shapes in Logo

`logo_shapes` · beginner · 3 checkpoints

Move the turtle, turn it, and draw closed shapes.

### Learning objectives

- Draw a single line with FORWARD
- Draw a square by repeating a move and a turn
- Work out the turn needed for a triangle

### Teacher notes

Logo is the only place in the studio where the output is a drawing rather than text, so check the canvas, not the console. The turn for a regular shape is 360 divided by the number of sides; let learners discover that for the triangle after doing the square.

### Checkpoints

#### 1. One line

Draw a single straight line 100 steps long.

Handout file: `logo_shapes-1.logo` · checked by draws: segments=1

Starting point:

```logo
RIGHT 45
```

Worked answer:

```logo
FORWARD 100
```

Hints, in the order a learner should see them:

1. FORWARD moves the turtle and draws as it goes.
2. The pen starts down, so FORWARD 100 makes one line.

#### 2. A square

Draw a square with four equal sides, ending where you started.

Handout file: `logo_shapes-2.logo` · checked by draws: segments=4, returns_home=True

Starting point:

```logo
REPEAT 4 [ FORWARD 100 ]
```

Worked answer:

```logo
REPEAT 4 [ FORWARD 100 RIGHT 90 ]
```

Hints, in the order a learner should see them:

1. A square needs a turn after each side.
2. The turn is 90 degrees: REPEAT 4 [ FORWARD 100 RIGHT 90 ]

#### 3. A triangle

Draw an equilateral triangle, ending where you started.

Handout file: `logo_shapes-3.logo` · checked by draws: segments=3, returns_home=True

Starting point:

```logo
REPEAT 3 [ FORWARD 100 RIGHT 90 ]
```

Worked answer:

```logo
REPEAT 3 [ FORWARD 100 RIGHT 120 ]
```

Hints, in the order a learner should see them:

1. The outside of a triangle turns through 360 degrees in total.
2. 360 divided by 3 sides is 120 degrees.

## Logo Procedures

`logo_procedures` · intermediate · 3 checkpoints

Name a shape once and draw it as often as you like.

### Learning objectives

- Define a procedure with TO and END
- Give a procedure an input
- Make a procedure call itself

### Teacher notes

Procedures are the reason Logo is worth teaching: the learner stops writing drawing and starts writing vocabulary. A procedure that calls itself needs a condition to stop, so the spiral checkpoint is also the first brush with recursion terminating.

### Checkpoints

#### 1. Teach the turtle a square

Define SQUARE, taking the side length as :SIZE, and draw one.

Handout file: `logo_procedures-1.logo` · checked by draws: segments=4, returns_home=True

Starting point:

```logo
TO SQUARE :SIZE
  REM Draw four sides here
END

SQUARE 80
```

Worked answer:

```logo
TO SQUARE :SIZE
  REPEAT 4 [ FORWARD :SIZE RIGHT 90 ]
END

SQUARE 80
```

Hints, in the order a learner should see them:

1. A procedure body goes between TO and END.
2. The input is used like a number: FORWARD :SIZE

#### 2. Any regular shape

Define POLY taking :N sides and :SIZE, and draw a hexagon.

Handout file: `logo_procedures-2.logo` · checked by draws: segments=6, returns_home=True

Starting point:

```logo
TO POLY :N :SIZE
  REPEAT :N [ FORWARD :SIZE ]
END

POLY 6 60
```

Worked answer:

```logo
TO POLY :N :SIZE
  REPEAT :N [ FORWARD :SIZE RIGHT 360 / :N ]
END

POLY 6 60
```

Hints, in the order a learner should see them:

1. One procedure should draw any shape, so the turn cannot be a fixed number.
2. The turn is 360 / :N - work it out inside the loop.

#### 3. A spiral that stops

Make SPIRAL draw a growing spiral: each step is longer than the last, and it stops once the step passes 60.

Handout file: `logo_procedures-3.logo` · checked by draws: segments=6

Starting point:

```logo
TO SPIRAL :SIZE
  FORWARD :SIZE
  RIGHT 90
  SPIRAL :SIZE + 10
END

SPIRAL 10
```

Worked answer:

```logo
TO SPIRAL :SIZE
  IF :SIZE > 60 [ STOP ]
  FORWARD :SIZE
  RIGHT 90
  SPIRAL :SIZE + 10
END

SPIRAL 10
```

Hints, in the order a learner should see them:

1. Without a stopping rule the procedure calls itself forever.
2. Stop at the top of the body: IF :SIZE > 60 [ STOP ]
